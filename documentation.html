Section 1

Global Settings

Menu → Settings → IPTV → Settings. These apply to the whole plugin, not to any single provider. A * after a field name means the plugin (or GUI) needs a restart for the change to take effect.

General

Enable IPTV manager *Yes/No — default: Yes

Enable IPTV functionality and management. This is the master switch for the entire plugin — turning it off disables all providers, menus and the web manager until turned back on.

Check for Networkoff / 1,2,3,5,7,10 sec — default: 2 sec

Checks that the network is available before trying to retrieve a playlist. If the network isn't reachable, the plugin falls back to backup services instead of failing immediately.

Request timeoutoff / 1,2,3,5,7,10 sec — default: 2 sec

Timeout in seconds for the HTTP requests used to fetch a playlist. Increase this on slow or unreliable provider servers to avoid premature failures.

Picon max threads50–1000, step 50 — default: 100

Maximum number of parallel threads used when downloading channel picons. If the box returns errors or fails to download some picons, lower this number.

Note: this is the global fallback. Each provider also has its own "Picon max threads" field (see Per-Provider settings) that overrides this value for that provider specifically.

Menus & Playback

Show 'Video on Demand' menu entry *Yes/No — default: Yes

Allows the "Video on Demand" entry to appear in the main menu.

Show 'Video on Demand' extensions entry *Yes/No — default: No

Allows the "Video on Demand" entry to appear in the Extensions (blue button) menu, as an alternative or addition to the main menu entry above.

Bouquet name character casedefault: UPPER case

Specifies the character case used for generated bouquet names and titles.

Choices
Original case · lower case · UPPER case
VoD playback systemdefault: HiSilicon/GStreamer

Specifies the type of service generated for Video on Demand items.

Choices
HiSilicon or GStreamer (label depends on your box's media service) · Exteplayer3 (only shown if the ServiceApp plugin is installed)
Download and display posters for VoD itemsYes/No — default: Yes

Download and display poster/cover artwork for VoD items, where the provider supplies it.

Size of buffer for http streaming1–20 MB — default: 2 MB

Configures the buffer size for HTTP streaming (this is a core Enigma2 setting the plugin also surfaces here for convenience). A larger buffer can help with stuttering on unstable connections, but increases the delay behind live TV.

Choices
1 MB · 2 MB · 4 MB · 8 MB · 16 MB · 20 MB
Fallback location for piconsConditional

Fallback location for picons, used when the currently active picon location can't be detected automatically.

Only shown when more than one candidate storage mount is detected on the box.

Catchup & EPG Server

Enable catchup/archive entries in EPG screens for periodcore Enigma2 setting

Enables the ability to scroll back in EPG screens to use older entries for invoking catchup/archive/timeshift playback.

Catchup/Archive EOF timeout1,2,3,5,7,10,15 sec — default: 3 sec

Timeout in seconds before the catchup/archive playback "end of file" event is acted on — delaying it avoids false end-of-stream detection on some providers.

Local EPG server listening port *number — default: 9010

TCP port for the plugin's local EPG server. This is mainly used to serve synthesized EPG for Stalker portals, which otherwise have no persistent standalone EPG endpoint.

Web Manager

Enable Playlist manager web interface *Yes/No — default: No

Enables a browser-based interface for viewing, adding, editing and deleting IPTV providers, reachable from any device on the local network.

Web interface listening port *Conditionalnumber — default: 8090

The TCP port on which the Playlist manager web interface listens.

Only shown when "Enable Playlist manager web interface" is set to Yes.
Require authentication *ConditionalYes/No — default: Yes

Protects the web interface with HTTP Basic Authentication, reusing the box's own system login — the same username/password used for the receiver's own web interface, Telnet and FTP (typically root). There is no separate web-manager-only account.

Only shown when "Enable Playlist manager web interface" is set to Yes.

Recording & Timeshift

These are core Enigma2 settings that M3UIPTV surfaces on its own settings page for convenience. Each is only shown if your specific image/build exposes the underlying attribute — so this section may look different across OpenPLI, OpenATV, OpenViX, etc.

Recordings - convert IPTV servicetypes to 1Conditional

Recording servicetypes 4097, 5001 and 5002 aren't possible with external players, so this converts recordings of those types to servicetype 1 instead.

Timeshift optionsConditional, per-image

A group of standard Enigma2 timeshift settings, shown only where the underlying config path exists on your image:

Auto-start timeshift after…Starts timeshift automatically in the background after a set delay.
Show warning when timeshift is stoppedPrompts with an option to stop or continue when timeshift would otherwise end.
Timeshift-save action on zapWhether timeshift continues when the channel is set to record.
Stop timeshift while recording?Stops timeshift use during an active recording — advisable for USB-stick storage.
Use timeshift seekbar while timeshifting?Allows using the seekbar to jump to a point within the event.
Skip jumping to live while timeshifting with pluginsAllows timeshift to be used together with alternative audio plugins.
ServiceApp playback settingsOnly if ServiceApp plugin installed
Enigma2 playback systemSwitches the playback engine to one of the players available in the ServiceApp plugin.
Player selectionSelects which ServiceApp player to use. Only shown if the setting above is enabled.

Scheduled Updates

Schedule updateYes/No — default: No

Turns on automated updates of providers. Also requires enabling "Auto updates" individually on each provider that should be refreshed by the schedule.

Schedule time of dayConditionaldefault: 01:00

The time of day at which the scheduled update runs.

Only shown when "Schedule update" is Yes.
Schedule days of the weekConditional

M3U
FilterConditionaldefault: tvg-id="{SID}"

The search pattern used to locate a channel's stream/service ID inside its #EXTINF line. The literal placeholder {SID} acts as a wildcard capture — everything else in the field is matched literally. With the default value, whatever text appears inside tvg-id="..." is captured as the service ID.

Only shown when "Use static URLs" is No.

Authentication

UsernameRequired for Xtream

Username used to authenticate with the streaming server.

XtreamTVHeadend
PasswordRequired for Xtream, masked input

Password used to authenticate with the streaming server.

XtreamTVHeadend
MAC address

The MAC address of an authorized device used to authenticate with the Stalker portal, e.g. 00:1A:79:XX:XX:XX. Changing this value clears any auto-generated Serial/Device ID/Signature below so they regenerate from the new MAC.

Stalker
SerialOptional, advanced

A custom device serial number. Leave empty to auto-generate it from the MAC address (the first 13 characters of its MD5 hash, uppercased).

Stalker
Device ID 1Optional, advanced

A custom primary device ID. Leave empty to auto-generate it from the MAC address (its SHA-256 hash, uppercased).

Stalker
Device ID 2Optional, advanced

A custom secondary device ID. Leave empty to reuse the same value as Device ID 1.

Stalker
SignatureOptional, advanced

A custom device signature. Use this if you copied Serial/Device ID values from a real device and streaming still fails — paste the signature from that same device. Leave empty to auto-generate it (SHA-256 of MAC + Serial + Device ID 1 + Device ID 2, uppercased). Changing Serial, Device ID 1, Device ID 2 or Signature itself clears the cached signature so it regenerates on save.

Stalker
Skip VOD entriesYes/No — default: Yes

Skips VOD (movies/series) entries found in the source, keeping only live channels for this provider.

Section 4

Validation Rules on Save

These checks run when you save a provider from the Add/Edit screen.

  • Provider name, URL and Scheme must all be filled in — saving is blocked with "All fields must be filled in." otherwise.
  • Scheme must be unique among all configured providers when adding a new one; a duplicate is rejected with a message naming the conflicting value.
  • For Provider Type Xtream Codes, Username and Password are also required.
  • On the day-of-week schedule screen, at least one day must remain enabled.
